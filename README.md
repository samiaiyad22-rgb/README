# Google Colab demos

A small collection of beginner-friendly Google Colab notebooks:

- `hello_colab.ipynb` demonstrates basic Python arithmetic.
- `creative_ideas.ipynb` uses the OpenAI API to suggest three uses for an everyday object.

Upload a notebook to [Google Colab](https://colab.research.google.com/) to run it. For the API notebook, enter your key in the hidden runtime prompt; never save it in a notebook or commit it. API use may incur charges.
